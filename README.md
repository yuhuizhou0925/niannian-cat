# desktop-cat

一只住在桌面底边的 3D 小猫。它会自己走动、吃饭、喝水、爬猫爬架、玩玩具，累了就钻进小房子睡觉。

用 Electron + three.js 写成，目前只在 macOS 上运行过。

## 启动

需要先装好 [Node.js](https://nodejs.org/)（开发时用的是 v24）。

```sh
git clone <这个仓库的地址>
cd desktop-cat
npm install
npm start
```

启动后猫出现在屏幕底部，菜单栏里会多一个 🐱 图标。要退出，点 🐱 → 退出。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 点食盆 / 水盆 | 加满猫粮 / 水 |
| 点逗猫棒的座子 | 拿起逗猫棒，毛球跟着鼠标走；再点一下任意位置把它挂在那儿 |
| 右键、按 Esc、或点座子 | 把逗猫棒放回座子 |
| 拖动小球 | 捡起来，松手时带着鼠标的速度扔出去 |
| 点小球 | 把它踢出去 |
| 点猫爬架 | 拨一下上面挂着的小球 |
| 拖动猫 | 把它拎起来，松手放下 |
| 连点猫三下 | 它会哈气 |
| 拖动任何道具 | 挪到别的位置 |
| 点房子 | 叫醒在里面睡觉的猫 |

房子正面是状态牌：门楣上写着它现在在干什么，门洞周围的三段弧分别是饱不饱（🍖）、精力（⚡）、渴不渴（💧）。某一段变红，说明这一项已经低到会影响它的行为，例如精力太低时逗它也不玩。

菜单栏的 🐱 里还可以调整整体大小、静音、收起猫爬架，以及打开两个编辑窗口：

- **定制外观**：改毛色、花纹、眼睛颜色和体型，内置布偶、橘猫、狸花等预设。
- **定制猫爬架**：改平台的数量、位置、样式和颜色。

## 其他命令

| 命令 | 作用 |
| --- | --- |
| `npm run studio` | 启动并直接打开外观工作室 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run build` | 只打包，不启动 |
| `npm run sculpt` | 用 Blender 重新生成猫的模型（需要装在 `/Applications/Blender.app`） |

## 目录

- `src/main.js`：Electron 主进程，负责透明置顶窗口和菜单栏
- `src/renderer/`：桌面上的猫，包括行为、骨骼动画、道具和描线渲染
- `src/studio/`：外观工作室
- `src/tree/`：猫爬架编辑器
- `tools/sculpt_cat.py`：生成猫模型的 Blender 脚本
- `assets/cat.glb`：生成好的模型
